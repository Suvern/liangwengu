# F# 规则

- 文件必须显式加入 `.fsproj`，并按依赖顺序排列；入口文件最后
- 移动或拆分文件时同步更新 `.fsproj` 并立即构建
- 模块用 PascalCase，函数和值用 camelCase
- 优先使用不可变值、模式匹配、`Option` 和 `Result`
- 纯逻辑不得依赖时间、UI、文件、网络或平台 API
- 外部输入先解析和校验，再进入领域逻辑
- 不用 `sprintf`、`printf` 或 `printfn` 的格式占位符，统一使用 F# 模板字符串，例如 `$"值：{value}"`
- 正常业务分支不用异常；异步代码避免同步等待
- 平台 API 放在平台文件中，用条件编译隔离
- 后台服务不直接操作 UI
- 领域测试使用固定输入，不依赖当前时间或外部服务
